# Biblioteca de prompts educacionais

Prompts em português para professores e estudantes universitários copiarem, adaptarem e usarem no modelo de sua escolha. Cada prompt é independente: os materiais necessários devem ser anexados ou colados **na própria conversa de uso**. Nenhum exige acesso ao Google Drive da oficina, ao caso Flor de Barro, ao aplicativo AI Teaching Studio ou a uma conversa anterior.

## Comece por aqui

1. Escolha um prompt no índice e abra o arquivo.
2. Copie somente o bloco "Prompt para copiar", ajuste os campos entre colchetes e envie seus arquivos no mesmo chat.
3. Revise o resultado antes de usar em aula, entregar ou publicar. Veja [as instruções completas e os formatos alternativos](COMO_USAR.md).

## Copiar e baixar

- **Um prompt:** abra o arquivo, copie o bloco; para salvar o arquivo, use o botão de download do GitHub ou abra **Raw** e salve como `.md`. Os rótulos podem variar na interface.
- **Todos em texto simples:** abra [PROMPTS_COMPLETOS.txt](PROMPTS_COMPLETOS.txt) e baixe o arquivo. Cada prompt tem um marcador de início e fim; envie apenas o escolhido ao modelo.
- **Pacote do repositório:** na página principal do GitHub, use **Code → Download ZIP** e extraia a pasta `prompts/`. Não é necessário instalar a aplicação nem usar Git.
- Arquivos Markdown (`.md`) também são texto e podem ser abertos em um editor comum.

## Integrações opcionais

Google Docs e Google Slides dependem das ferramentas disponíveis na conta e no chat de quem usa o prompt. A primeira opção é criar documentos reais quando houver integração; as alternativas são arquivos editáveis ou conteúdo estruturado para copiar. O miniapp oferece HTML autônomo mesmo quando o chat não executa interativos. Nenhum prompt exige chave de API.

## Acesso e distribuição

Esta cópia está no repositório público [prompts-oficina](https://github.com/cecil-ia-labs/prompts-oficina). Qualquer participante pode consultar ou baixar os arquivos sem acesso à demo ou a pastas privadas. Para baixar tudo de uma vez, use **Code → Download ZIP** e abra a pasta `prompts/`. Os modelos podem exigir internet conforme o serviço escolhido.

Veja também as [instruções de personalização do ChatGPT](../personalizacao/README.md).

## Alcance

São instruções reutilizáveis, não uma automação instalada. Os resultados dependem do modelo, dos anexos e das ferramentas disponíveis. Não pressupõem inferência executada, arquivo gerado ou publicação realizada. Decisões pedagógicas e a revisão da autoria, dos dados e das referências cabem a quem utiliza os materiais.
